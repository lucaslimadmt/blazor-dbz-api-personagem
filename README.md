# Consulta de personagens de Dragon Ball com Blazor

Projeto acadêmico desenvolvido em **C#**, **.NET 10** e **Blazor Web App (Interactive Server)** para consultar personagens pela [Dragon Ball API](https://dragonball-api.com/).

## Funcionalidades

- Buscar um personagem pelo ID informado.
- Exibir nome e planeta de origem.
- Listar as transformações retornadas pela API.
- Apresentar mensagens para IDs inválidos e falhas na consulta.

## Tecnologias

C#, .NET 10, Blazor Interactive Server, HttpClient, Newtonsoft.Json e Bootstrap.

## Como executar

Instale o [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0). Na pasta do projeto, execute:

```bash
dotnet restore
dotnet run
```

Abra o endereço local mostrado no terminal e informe o ID de um personagem.

A busca requer acesso à internet e disponibilidade da Dragon Ball API.
